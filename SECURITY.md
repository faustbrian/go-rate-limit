# Security policy

Report suspected vulnerabilities privately through GitHub Security Advisories
for this repository. Do not open a public issue with credentials, raw request
identities, exploit details, or production data.

Only the latest patch of the latest released minor of the latest major
receives security fixes. Superseded majors, including v1 and v2, remain
published but receive no further releases.

Reports should include the affected version, policy/backend, minimal
reproduction, impact, and whether trusted-proxy or key configuration is
involved.
