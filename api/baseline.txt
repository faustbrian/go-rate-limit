package ratelimit // import "github.com/faustbrian/go-rate-limit/v2"

Package ratelimit defines transport-neutral admission policies, requests,
decisions, observations, batching, and concurrency leases.

The package performs no sleeping or retry orchestration. Backends implement
atomic state changes, while Service applies the policy's explicit failure
mode and emits observations. StrictService validates explicit backend outcome
declarations and never fails open on an unknown mutation result. Service retains
its released compatibility behavior and does not validate those declarations.
Neither service owns backend shutdown or application retries.

Policy consistency is a declaration, not backend selection or verification.
Callers choose the authority and supply time, non-secret policy labels and keys.
Leases account for capacity; they do not authenticate callers or fence
application side effects after expiry.

FUNCTIONS

func CanceledOutcome() error
    CanceledOutcome constructs a bounded declaration that dispatch did not
    occur. It matches ErrCanceled, context.Canceled and, for compatibility,
    ErrDeadline. A backend is responsible for the truth of this declaration.

func DeadlineOutcome() error
    DeadlineOutcome constructs a bounded deadline declaration that dispatch did
    not occur.

func UnknownOutcome(contextCategory error) error
    UnknownOutcome constructs a bounded declaration that dispatch may have
    occurred. Only direct context.Canceled or context.DeadlineExceeded adds
    a classification; the supplied error, its text, cause and tree are not
    retained or traversed.

type Decision struct {
	// Allowed reports whether the operation may proceed.
	Allowed bool
	// Remaining is the immediately available whole-unit capacity.
	Remaining uint64
	// Limit is the configured Capacity plus Burst.
	Limit uint64
	// Reset is the earliest useful replenishment or lease expiry time.
	Reset time.Time
	// RetryAfter is the minimum suggested delay after rejection.
	RetryAfter time.Duration
	// Reason is a stable machine-readable classification.

type Key struct {
	// Has unexported fields.
}
    Key is an immutable, validated backend key. Its zero value is invalid.
    Subject kind is syntactically bounded, not verified to be low-cardinality.

func NewKey(spec KeySpec) (Key, error)
    NewKey validates and derives a namespaced key from spec. Namespace,
    version and kind are 1..48 lowercase ASCII letters, digits, hyphens or

    authenticity and privacy.

func (k Key) String() string
    String returns namespace:version:kind:value, or empty for a zero Key. With
    Hash false this includes the raw subject; do not log it as safe metadata.

func (k Key) SubjectKind() string
    SubjectKind returns the syntactically bounded category, or empty for a zero
    Key.

type KeySpec struct {
	// Namespace isolates applications or package consumers.
	Namespace string
	// Version permits intentional key derivation changes.
	Version string
	// Subject supplies the typed identity.
	Subject Subject
	// Hash derives a SHA-256 digest from namespace, version, kind and value.
	// False persists the raw value; neither mode is encryption or authentication.
	Hash bool
}
    KeySpec describes a namespaced and versioned admission key.

type Lease struct {
	// ID is the caller-generated lease identity.
	ID string
	// Key identifies the concurrency state.
	Key Key
	// PolicyID identifies the owning policy.
	PolicyID string
	// PolicyRevision identifies the semantics used when acquiring the lease.
	PolicyRevision string
	// Cost is the held concurrency weight.
	Cost uint64
	// ExpiresAt is the logical expiry boundary. Backends prune on later work,
	// explicit sweeping or state TTL; no callback stops application work.
	ExpiresAt time.Time
	// Backend identifies the implementation that created the lease.
	Backend string
}
    Lease records weighted concurrency ownership until ExpiresAt or release.
    Fields are public and forgeable: possession is not authenticated
    authorization or a fence for application side effects. Copy the value;
    do not mutate it between acquisition and release.

type Request struct {
	// Policy contains immutable admission semantics.
	Policy Policy
	// Key identifies the bounded subject state.
	Key Key
	// Cost is the positive number of units requested.
	Cost uint64
	// Now is required even with server-clock backends. Client-clock backends
	// use its microsecond-normalized instant and clamp backward movement per key.
	Now time.Time
}
    Request is a weighted admission attempt evaluated at an explicit time.

func (r Request) Validate() error
    Validate checks policy/key presence, positive Cost within MaxCost and a
    nonzero Now inside the exact Unix-microsecond range with room for the policy
    duration. It does not validate backend capability or clock synchronization.

type Service struct {
	// Has unexported fields.
}
    Service validates requests, applies compatibility failure behavior,
    and emits observations. Use NewService and a non-nil context; a zero or
    nil Service is not usable. It owns no clients, goroutines or shutdown.
    Concurrent calls may invoke the borrowed backend and observers concurrently.

func NewService(backend Backend, observers ...Observer) (*Service, error)
    NewService constructs a service, filtering nil observers up to MaxObservers.
    It calls backend.Name during construction and again during operations.
    Typed nil backends are not rejected; use NewStrictService for strict nil
    validation.

func (service *Service) Acquire(ctx context.Context, request LeaseRequest) (lease Lease, decision Decision, err error)
    Acquire validates and atomically obtains a concurrency lease.

func (service *Service) Admit(ctx context.Context, request Request) (decision Decision, err error)
    Admit evaluates one request synchronously without sleeping or retrying.
    Backend success/rejection results are not checked for completeness. Other
    errors are normalized; non-concurrency FailOpen can admit on availability
    or deadline errors without knowing whether a backend mutation occurred.
    Observer calls are synchronous with panics isolated, but blocking is not
    time-bounded.

func (service *Service) Batch(ctx context.Context, batch BatchRequest) (BatchDecision, error)
    Batch validates all inputs before any dispatch, then processes every item
    independently in order with no rollback or hidden retries. It does not
    stop the loop on cancellation; each Admit/backend applies its own context
    behavior. The returned decisions are caller-owned and item errors are
    joined.

func (service *Service) Release(ctx context.Context, lease Lease) error
    Release relinquishes a lease through the backend that owns it.

type StrictService struct {
	// Has unexported fields.
}
    StrictService validates complete backend results and fails closed on
    ambiguity. Construct it with NewStrictService; nil/zero receivers and
    nil contexts are rejected. Collaborators are borrowed, may be called
    concurrently, and are not closed. Backend panics propagate; observer panics
    alone are isolated.

func NewStrictService(backend StrictBackend, observers ...Observer) (*StrictService, error)
    NewStrictService rejects nil/typed-nil backends and typed-nil observers,
    filters nil observers, and caches one validated backend.Name call. That
    call may panic; no admission operation is invoked and no client lifetime is
    owned.

func (service *StrictService) Acquire(ctx context.Context, request LeaseRequest) (Lease, Decision, error)
    Acquire validates and obtains one strict concurrency lease. A complete known
    result wins racing cancellation; incomplete lease/result pairs are unknown
    and fail closed. Concurrency never fails open and backends own expiry
    semantics.

func (service *StrictService) Admit(ctx context.Context, request Request) (Decision, error)
    Admit validates and executes one strict admission request. A complete known
    result wins a racing cancellation. Unknown or malformed results fail closed;
    only known pre-dispatch deadlines or safe availability failures can fail
    open for a non-concurrency policy. No unsafe error tree is traversed or
    formatted.

func (service *StrictService) Batch(ctx context.Context, batch BatchRequest) (StrictBatchDecision, error)
    Batch validates every item before dispatch, then evaluates in order
    without rollback. Cancellation/deadline before dispatch stops the suffix;
    an ambiguous attempted item plus caller cancellation also stops it.
    Completed effects remain. Decisions and Attempted are caller-owned; errors
    contain ordered item failures.

func (service *StrictService) Release(ctx context.Context, lease Lease) error
    Release relinquishes one strict lease without observing or retaining it.
    Nonempty Backend must match the cached name; empty Backend is accepted for
    compatibility. Known success wins racing cancellation. Ownership fields are
    checked, but the public Lease value is not cryptographic authorization.

type Subject struct {
	// Kind is a syntactically bounded subject category; callers control cardinality.
	Kind string
	// Value is a 1..MaxSubjectBytes-byte identity input. Avoid raw secrets even
	// when hashing: deterministic hashes permit guesses of low-entropy values.
	Value string
}
    Subject is a typed identity input used only to derive a bounded Key.

package ratelimithttp // import "github.com/faustbrian/go-rate-limit/v2/adapters/http"

Package ratelimithttp provides strict inbound HTTP rate-limit middleware at
github.com/faustbrian/go-rate-limit/v2/adapters/http.

The middleware is synchronous and borrows callbacks, service and handler.
Callbacks may block or panic and must support concurrent requests. Proxy trust
is configured by network prefix; forwarded headers are trusted only from a
trusted direct peer, not authenticated by this package. Admission does not own
request-body buffering, outbound pacing, retries or application shutdown.

    NewClientIPExtractor validates and copies trusted proxy prefixes.

func (extractor *ClientIPExtractor) ClientIP(request *http.Request) (netip.Addr, error)
    ClientIP rejects nil/zero extractors and nil requests. It ignores forwarding

    if all are trusted. Header.Get selects the first X-Forwarded-For line.

    authentication.

	// Has unexported fields.
}
    Middleware holds validated immutable HTTP admission state.

func New(options Options) (*Middleware, error)
    New validates options without invoking a downstream handler.

func (middleware *Middleware) Wrap(next http.Handler) (http.Handler, error)
    Wrap rejects nil/typed-nil handlers. Each call derives Key, Cost and Now
    in order, then admits before invoking next once. Callbacks are borrowed,
    may run concurrently and may block/panic; the middleware adds no deadline.
    Derivation errors produce 400, rejection 429, and other admission failures
    503. Reset and retry headers round nonnegative relative seconds upward,
    not Unix timestamps.

type Options struct {
	// Service performs strict admission.
	Service *ratelimit.StrictService
	// Policy is applied to every request.
	Policy ratelimit.Policy
	// Now supplies request time; nil uses time.Now.
	Now func() time.Time
	// Cost derives request cost; nil uses one.
	Cost func(*http.Request) (uint64, error)
	// Key derives the admission key; nil uses the validated client IP.
	Key func(*http.Request) (ratelimit.Key, error)
	// ClientIP configures trusted proxy handling for the default key function.
	ClientIP ClientIPOptions
}
    Options configures strict inbound HTTP admission.

package valkey // import "github.com/faustbrian/go-rate-limit/v2/valkey"

Package valkey provides atomic distributed admission backed by native Valkey.
Keys use one opaque hash tag, scripts are versioned, and state has bounded TTL.

The client is borrowed. Startup checks observe Valkey 9+ and noeviction once;
operators own ongoing configuration and replication durability. Lua executes
on one authoritative key/slot; script atomic execution is not rollback after
a runtime error. Strict transport/reply ambiguity never proves safe retry.
Released methods retain legacy revision and error-normalization behavior.

CONSTANTS

const MaxPrefixBytes = 64
    MaxPrefixBytes bounds the operator-controlled portion of persisted keys.

type ClockPolicy uint8
    ClockPolicy selects the authoritative time source for state transitions.

	// ClientClock uses Request.Now and clamps rollback per key.
	ClientClock ClockPolicy = iota
	// ServerClock uses Valkey's TIME result inside the atomic script.
	ServerClock

type Options struct {
	// Prefix namespaces keys and must contain no spaces or hash-tag characters.
	Prefix string
	// Timeout bounds each admission and lease operation; checks use the caller context.
	Timeout time.Duration
	// Clock selects client or server time.
	Clock ClockPolicy
}
    Options configures Valkey key names, deadlines, and clock authority.

type Store struct {
	// Has unexported fields.
}
    Store executes per-key Lua operations against a borrowed native Valkey
    client. Use a constructor; do not copy internal configuration after use.
    Atomicity is on the selected server, not a durability or replica guarantee.
    The store never closes the client or owns application retry orchestration.
